ESP32 USB to AirPrint

Install the firmware on your ESP32-S3 from this page, then set up its WiFi. No software to install. About the project

1. Plug the board into this computer

  1. An ESP32-S3 board with 16 MB flash and 8 MB PSRAM (N16R8) and two USB-C ports.
  2. Use the port marked COM (or UART), not the one marked USB. The USB port is for the printer, and the WiFi setup below only works over the COM port.
  3. Use Chrome or Edge on a computer. Safari, Firefox and phones cannot talk to USB devices from a web page.

2. Install

This browser cannot install the firmware: open this page in Chrome or Edge on a computer. The installer needs a secure page: open it over https (or from localhost).
  1. Click Connect and pick the board's serial port (often "USB Single Serial", "CP210x" or "CH340").
  2. On a board that never ran this firmware, let it erase the board first.
  3. If it cannot connect: hold the board's BOOT button, press RST, release BOOT, then try again.

No serial port in the list? The board's USB-to-serial chip may need a driver: CH340/CH343 or CP210x. On Linux, add yourself to the dialout group.

3. Connect it to your WiFi

  1. After installing, the installer offers Connect to Wi-Fi: pick your network (2.4 GHz) and type its password.
  2. Then Visit Device opens the printer's web page. It is also at http://canon-mg2500.local/.
  3. To change the network later, plug the COM port in again, click Connect and choose Change Wi-Fi.

4. Plug in the printer

  1. Connect the printer to the board's port marked USB and power the board (the COM port can stay on a phone charger).
  2. Bridge the board's USB-OTG solder pads so that it gives the printer 5 V: most printers only appear when they see it.
  3. Print from an iPhone, iPad or Mac (AirPrint), Android (Mopria), or from the board's web page; scan from the web page or Image Capture.
Firmware: MIT. The installer is ESP Web Tools (Apache-2.0); the WiFi setup uses Improv Wi-Fi.
