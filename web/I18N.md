# Web UI translations

The UI supports English (`en`) and Simplified Chinese (`zh-CN`). The language button opens a compact picker below the online status in the navigation menu (on phones, return to the menu first). A saved choice takes priority over browser preferences. Switching works even when storage is restricted. The HTML language and page title follow the selection.

## Updating text

Use `t('English source sentence')` instead of hard-coded UI text. All Chinese translations live in `src/lib/locales/zh-CN.ts`, alphabetically ordered by English source message. English source messages are the keys and the English fallback; no duplicate English catalog is needed. The inferred `Message` type catches unknown keys during type checking.

Use complete sentences with named placeholders, such as `t('Scanning · {percent}%', { percent: 42 })`. Add a Chinese translation with the same placeholders. Avoid concatenating words. Keep protocol values, filenames, model names and user input unchanged. Use separate singular/plural messages for English and the active locale for dates and numbers. Unknown device or third-party errors retain their original text.

Svelte components import `t` and `i18n` from `i18n.svelte`. Plain TypeScript imports `t` from `i18n.ts`; the browser wrapper installs the reactive locale reader. This small split keeps Node tests independent of Svelte's compiler while letting UI translations react to language changes. Evaluate translations in render/derived expressions, rather than caching translated strings at module initialization. Transient notifications use the language active when they occur.

## Adding a language

Add one entry to `localeConfig` in `src/lib/i18n.ts` with the native display name, browser language prefix and a complete catalog. The `Locale` type, language detection and picker options derive from this registry. Catalogs must cover every `Message`; type checking catches missing entries. English remains the fallback. No external service or runtime dependency is required.

`components/LanguagePicker.svelte` owns the presentation and interaction. It uses native radio controls for arrow-key navigation, Escape to close and restore focus, and outside-click dismissal. The sidebar only mounts the component below the status indicator.

## Verification

Run `npm run check`, `npm test` and `npm run build` in `web/`. Translation tests verify language negotiation, literal interpolation and placeholder parity. Browser verification should include switching without reload, reload persistence, page titles, all four routes, dialogs, phone layouts and restricted storage.
